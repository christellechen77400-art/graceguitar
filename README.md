# Kinnor

Le manche de guitare, pour la louange. Gammes, accords, CAGED, analyseur d'accords, accords de la
tonalité avec chiffrage Nashville, progressions courantes et calcul du capodastre. FR / EN.

```bash
npm install
npx expo install --fix
npx expo start
```

Voir `CLAUDE.md` pour l'architecture et la suite du développement.
